strategy-rs 运行全景 架构双路径扩展交易所回测时序实盘时序模式对比存储状态机可靠性

一套引擎，两条路径：回测 / 实盘运行全景

strategy-template-rs 是 Rust CTA 策略脚手架。核心公理：回测与实盘跑同一段主循环（ExchangeRunner），规则对象是同一批 Arc，模式差异只收口在两个装配端口（行情源、订单出口）。本页为纯静态 SVG，可离线直接打开；全部结论带 file:line 证据（branch feat/ctp-integration 工作区直读）。

系统拓扑

交易链路不直连交易所：run 只经 trading-service 一个外部服务——下单/回报与 K 线共用同一条 WS（subscribe_kline 定稿 kline_1m_batch、历史 get_klines；klines-service 已退役，旧 services.kline 配置节写了 run 即拒启）；backtest 与 download 只吃本地 CSV。CTP/币安的实际撮合、金额单换算、平今平昨都在 trading-service 侧（contracts/trading-service.md §7）。一条 WS 连接绑定一个策略身份：握手 strategy_name + nonce + HMAC-SHA256（contracts/trading-service.md §1）。

双路径的分叉点只有两个

Exchange trait 把「规则」与「怎么连」正交拆开：session/聚合/交易/仓位规则 build 时同一批注入，只有 make_source（行情）与 make_execution（订单出口）按 RunMode 分叉（crates/engine/src/core/exchange.rs:97-128）。两条路径最终产出的都是同构 Fill——报表、账户、仓位更新的唯一数据源（crates/engine/src/core/execution.rs:102-125）。

回测特有实盘特有两者共用

扩展交易所：新增一个场所要在哪接线

框架公理是规则与运行模式正交——扩展的主体工作是声明「这个场所的规则是什么」（六个规则对象），实盘再补两个端口的薄装配；协议层（wire.rs/HMAC/ack 对账）与主循环（ExchangeRunner/SignalManager/PositionManager/Store）一行不碰。只做回测的话，到②默认端口就结束了。

可靠性机制清单（为什么敢用回测口径跑实盘）

  • 确定性键：signal_id 纯由事件时间派生、禁 now() → 断线/重启重发天然幂等（core/src/signal.rs:122-150）。
  • B5 在途约束：Created..Accepted 的 Open 拦重复开仓；同 position_id 的 Close 在途去重（crates/signals/src/manager.rs 内核）。
  • 平仓 fail-closed：无仓位或无「开仓 FILLED 回报逐字成交量」不发帧；平仓成交到达但无仓位 → 丢弃绝不反手（spi_live_actor.rs:488-520,531-545）。
  • 三层对账：重启/重连 reconcile 先查后发；每分钟远程仓位对账（仅 live，fail-open）；在途看门狗 get_order 补丢帧（spi_live_actor.rs:692-946）。
  • ReduceOnly 拒单 ≡ 交易所已无仓 → external_close 对齐（CTP 不覆镜像账本的例外如实登记，spi_live_actor.rs:646-687）。
  • 行情自愈：Lagged/Reconnected → backfill 本地 CSV+REST 补缺，只推进聚合不重放策略信号（spi_live_actor.rs:951-977,1131-1141）。
  • 安全闸：submit_enabled 默认 false；paper 装配层强制 false；占位端点+live 拒启、占位端点+paper 日志明告「不会真实下单」（main.rs:517-539）。
  • 等价性钉：backtest_paper_parity / spi_dual_run_parity / spi_engine_cli_parity 把「同一 Ctx、同一 Fill、逐分钟权益」钉成回归资产（crates/app/tests/）。
已知边界（别当已完成）：live 止损冷却写入触发未通（待 Phase 5α）；真实服务暂不强制 HMAC；xili 模拟器不推行情 ⇒ 金额单被拒、仅 quantity 平仓链路可验（RUNBOOK §4）；止盈止损是闭合 1m 粒度，触发到成交有一根 bar + 异步回报的滑点。
